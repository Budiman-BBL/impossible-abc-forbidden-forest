Kem Api Unggun

Kelas anda tersesat dalam hutan kampung pada waktu malam. Api unggun ialah nyawa anda. Jaga api, luaskan cahaya, dan hidupkan tiga kem sebelum gelap menelan semuanya.

Cara bermain

  • Tap pokok untuk hantar pekerja tebang kayu.
  • Tap api unggun untuk masukkan kayu daripada stok.
  • Seret untuk gerakkan kamera. Cubit atau roda tetikus untuk zum.
  • Jangan biarkan sesiapa berdiri dalam gelap lebih daripada 4 saat.
  • Upgrade Api membesarkan cahaya dan membuka watak baru.
  • Hantar Obor: Hanan membawa cahaya ke tapak kem. Obor ada tempoh — kem yang jauh perlu disambung daripada kem yang sudah menyala.
  • Bila Asiya dan Safiya bersama, Api Ajaib boleh menyalakan kem dari jauh.
  • Anda menang bila 3 kem menyala. Anda kalah jika api utama padam atau Cikgu Nisa diambil.

Rehat

Hutan masih menunggu. Api masih menyala — buat masa ini.
