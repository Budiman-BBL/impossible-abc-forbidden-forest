# Art bible (Sprint 1 draft)

**Primary reference:** `docs/art-reference/ABC_forbidden_forest_official_style_v2.png` (decision D6).
History: style v1, lineup v4, binatang v1, tempat_prop v1. UI layout: `ABC_forbidden_forest_ui_mockup_v1.png`.

## Style
Hand-drawn 2D, gothic storybook, organic ink outlines, expressive faces, muted earthy colours, dark forest, warm campfire light, fog and shadow. Family-friendly spooky. No copying of other games' assets, UI or code.
