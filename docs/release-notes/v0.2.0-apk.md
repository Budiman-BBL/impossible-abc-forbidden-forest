## Impossible ABC v0.2.0 — first Android APK

**Install (Android 7.0 or newer):** download `ImpossibleABC-v0.2.0-apk.apk` below, open it, and allow
"Install unknown apps" for the browser/Files app when Android asks. Play Protect may warn that the
app is from an unknown developer: tap *More details → Install anyway*.

What is in it:
- The Sprint 1 campfire loop (tap lit trees for wood, tap the fire to feed it, upgrade the fire, game over when it goes out).
- Fills the whole screen in landscape, no black borders; HUD buttons are thumb-sized.
- Landscape locked, immersive fullscreen (status/navigation bars hidden; swipe from the edge to show them), screen stays on while playing.

Not yet: character select, walking, inventory, day/night, saving, monsters, audio. All art is interim.
Signed with the project release key, so future APKs install as updates over this one.
