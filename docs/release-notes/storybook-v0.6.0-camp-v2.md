**Kem v2 — build ujian (pre-release, bukan untuk produksi).**

App sama seperti v0.5.0 (`com.budimanbbl.impossibleabc.storybook`), jadi boleh dipasang sebagai kemas kini atas v0.5.0 (versionCode 3, 0.6.0-camp-v2).

- **Kem baru:** kawasan lapang rata di tengah peta, unggun api di tengah, 3 khemah (Cikgu Nisa, budak lelaki, budak perempuan), meja dengan bangku, rak simpanan, dan batu huruf A yang makin menyala bila unggun api berjaya dihidupkan.
- **Cikgu Nisa hidup:** dia duduk di meja, bangun, berjalan (animasi jalan sebenar) dan berdiri di sekitar kem; berhenti dan berpaling bila Affan datang untuk bercakap.
- **Pagar malam 1:** pagar kayu lemah keliling kem, ada yang senget, separuh patah dan runtuh — ada lubang, serigala masih boleh masuk.
- **Laluan tanah** keluar dari kem ke Belukar Kayu (barat daya), Lembah Batu (tenggara) dan Hutan Larangan (timur laut); bahan dikutip di sepanjang laluan.
- Peta tetap 4800×4000 (sama setiap kali main). Getah dibuang; butang Interaksi tidak aktif bila panel Beg/Bina dibuka.
